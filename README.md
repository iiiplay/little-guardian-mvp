# 小小守護者 · MVP 0.9

自動探索、偶爾守護的手機直向小遊戲。本專案獨立於 Claude 的 dungeon-100 目錄。

玩家負責撿寶充能、抓準時機打斷、三擊流星與合成武器。勇者負責自動移動、戰鬥與離場。

最新程式優化維持 0.9 的玩法與存檔：減少尋路配置、靜態地形重繪、同步尺寸讀取及重複 HUD／觸控寫入。測量方法、前後數據、畫面與狀態相容性驗證見 [PERFORMANCE.md](PERFORMANCE.md)。

## 0.5 戰鬥重做

- 星能上限 3，每 6 秒回復 1；手動撿一件寶物立即回復 1。自動撿寶保留，但不給手動充能獎勵。
- 點敵人消耗 1 星能，冷卻 0.55 秒。5 秒連擊窗口內第三擊落下範圍流星；紅圈蓄力時命中可打斷並提高傷害。
- 每親手收集 5 件寶物，進入 8 秒攻速翻倍的狂熱。點炸藥桶可爆炸、連鎖，且不傷勇者。
- 第二波移動更快；第三波有精英。哥布林瞄準投射、飛行怪短距衝刺、頭目蓄力範圍攻擊。護甲祝福增加反傷，讓防禦路線保有輸出。
- 命中停頓、畫面震動、受擊變形、碎屑與爆炸動畫；減少動態偏好會關閉震動與停頓。新增分層合成音效，開始遊戲後解鎖播放，可靜音。
- 結算顯示玩家星擊、打斷、流星與手動撿寶戰績。裝備、合成和舊存檔保留。

驗證：`npm test` 包含既有 492 項檢查與新增戰鬥回歸、120 次主動／觀看對照；另有 `tests/combat_browser.cjs` 的實際 DOM 點擊、自然時間通關、暫停與手機尺寸測試。音效離線渲染檢查與試聽檔在 `artifacts/audio-results.json` 和 `artifacts/combat-sound-preview.wav`。

## MVP 範圍

10 關、5 種房間配置、3 種敵人、地刺、最後一關加冕史萊姆頭目。每關 3 波，自動尋路、近戰、開箱、離場。關卡 4 起有地刺，10 關有範圍蓄力頭目。

守護每關 2 次，回復 42 HP、無敵 6 秒、冷卻 18 秒。1× / 2× 速度、可選音效、暫停、關卡地圖、重試、首通三選一永久升級。過關 12 秒沒操作會選擇攻擊升級並前往下一關。背景自動暫停。

## 撿寶與裝備（0.2）

- 打怪掉落金幣袋，每四隻怪額外掉一瓶回復 12 HP 的藥水。直接點地圖上的寶物即可撿取；8 秒沒點會自動收取，離場也會補收剩餘物品。
- 打完第一波後可點右上寶箱，獲得 20 關卡金幣與一件裝備。第一件保證為武器，後續可能是武器、護甲、飾品；品質分普通、精良、稀有、史詩。沒點時，勇者清完三波後會代開。每趟寶箱只能開一次。
- 點守護按鈕右側的盾牌開啟裝備背包。打開背包會暫停；選欄位、比較數值、穿戴或卸下，關閉後繼續。武器加攻擊，護甲加生命與減傷，飾品加生命與攻速。裝備立即生效，生命按原比例調整，無法靠反覆換裝補血。
- 裝備開箱後立即存檔，失敗仍保留。重玩可收集裝備；首通祝福與金幣仍不重複發放。尚未實作出售、強化、商店與完整換裝外觀。

## 裝備特性與開箱（0.3）

- 回甘武器：普攻回復實際造成傷害的 15–24% 生命；過量傷害不會增加吸血。
- 跳跳雷武器：每第 3 次普攻，雷擊目標周圍 3 格內最多 2 隻怪，造成普攻的 45–60% 傷害。附雷擊線條、傷害字與藍色劍光。
- 刺刺護甲：受到敵人實際攻擊時反彈 2–7 傷害；無敵時不觸發，地刺不反傷。角色身邊有綠色小刺標記。
- 暖光飾品：每波結束額外回復 6–12 HP。舊裝備在讀取時依欄位補上有效特性，保留原本 ID、等級、品質與穿戴狀態。
- 每第 5 件新裝、以及第 10 關頭目箱，至少為稀有品質。其他品質機率維持普通 55%、精良 28%、稀有 14%、史詩 3%（保底箱會提升結果）。
- 手動開箱會暫停並揭曉裝備、品質、數值與特性，可直接穿戴；8 秒沒操作會收好並繼續，切到背景會停止倒數。勇者代開的寶箱只顯示取得提示，不打斷觀看。

## 玩家參與：武器合成與補刀（0.4）

- 背包武器旁有「合成」。兩把同品質武器合成高一階，保留主武器特性，等級取較高者；普通 → 精良 → 稀有 → 史詩（上限）。不消耗金幣。
- 合成畫面會列出主武器、素材、結果，再按「合成並穿戴」。兩把原武器會消耗，新武器立即穿戴並儲存。正在穿戴的武器可當主武器，不能當素材；缺少素材或已滿階時不能合成。
- 點戰場上的怪物施放星光補刀，每關 3 次、8 秒冷卻，造成至少 18 或勇者攻擊力 2 倍傷害，打斷出招並暈眩 1.2 秒。補刀擊殺與一般擊殺一樣會掉寶。冷卻、暫停與切到背景的時間都由同一模擬時鐘管理。
- 戰場下緣顯示補刀剩餘次數或冷卻，點寶物優先於點怪物，鎖住的寶箱不攔截補刀操作。
- 新箱裝備欄位機率改為武器 60%、護甲 20%、飾品 20%，讓玩家更容易累積合成素材。保底以「開箱次數」獨立計算，合成不會跳過或觸發開箱保底。

進度存於 localStorage（little-guardian-mvp-v1），存檔結構版本 4，沿用舊 key 以保留原進度。包含已通關、已解鎖、永久祝福、首通金幣、全部裝備、特性、穿戴狀態及開箱保底計數；舊存檔會補上缺少欄位。不儲存戰鬥中位置；重新開啟從已解鎖關卡重開。刷新過關畫面會補發一次預設攻擊祝福。關卡地圖可免費重新分配祝福，下次出發生效。金幣目前為紀錄，未實作商店。
