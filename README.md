# 小小守護者 · MVP 0.2

自動探索、偶爾守護的手機直向小遊戲。本專案獨立於 Claude 的 dungeon-100 目錄。

- 專案位置：`D:\Project\little-guardian-mvp`。
- 遊玩：雙擊本目錄 `index.html` 或 `dist/game.html`，不需安裝、連網或執行建置。
- 手機：在同一 Wi-Fi 啟動 `python -m http.server 8765 --bind 0.0.0.0`，手機開啟電腦區網 IP 的 `http://IP:8765/dist/game.html`。網路防火牆可能需要允許；正式公開網址尚未部署。
- 建置：`npm run build`；測試：`npm test`。
- 全部 PNG 嵌入單一 HTML；原始素材未修改。
- 美術：o_lobster，https://o-lobster.itch.io/ 。來源資料夾只附作者說明，公開發行前需核對購買頁授權。

## MVP 範圍

10 關、5 種房間配置、3 種敵人、地刺、最後一關加冕史萊姆頭目。每關 3 波，自動尋路、近戰、開箱、離場。關卡 4 起有地刺，10 關有範圍蓄力頭目。

守護每關 2 次，回復 42 HP、無敵 6 秒、冷卻 18 秒。1× / 2× 速度、可選音效、暫停、關卡地圖、重試、首通三選一永久升級。過關 12 秒沒操作會選擇攻擊升級並前往下一關。背景自動暫停。

## 撿寶與裝備（0.2）

- 打怪掉落金幣袋，每四隻怪額外掉一瓶回復 12 HP 的藥水。直接點地圖上的寶物即可撿取；8 秒沒點會自動收取，離場也會補收剩餘物品。
- 打完第一波後可點右上寶箱，獲得 20 關卡金幣與一件裝備。第一件保證為武器，後續可能是武器、護甲、飾品；品質分普通、精良、稀有、史詩。沒點時，勇者清完三波後會代開。每趟寶箱只能開一次。
- 點守護按鈕右側的盾牌開啟裝備背包。打開背包會暫停；選欄位、比較數值、穿戴或卸下，關閉後繼續。武器加攻擊，護甲加生命與減傷，飾品加生命與攻速。裝備立即生效，生命按原比例調整，無法靠反覆換裝補血。
- 裝備開箱後立即存檔，失敗仍保留。重玩可收集裝備；首通祝福與金幣仍不重複發放。尚未實作出售、強化、商店與完整換裝外觀。

進度存於 localStorage（little-guardian-mvp-v1），存檔結構版本 2，沿用舊 key 以保留原進度。包含已通關、已解鎖、永久祝福、首通金幣、全部裝備與穿戴狀態；舊存檔會補上空背包。不儲存戰鬥中位置；重新開啟從已解鎖關卡重開。刷新過關畫面會補發一次預設攻擊祝福。關卡地圖可免費重新分配祝福，下次出發生效。金幣目前為紀錄，未實作商店。

`engine/engine.js`：純模擬、種子、關卡與數值。`src/core.js`：流程與存檔。`src/driver.js`：引擎介面。`src/render.js`：Canvas。`src/ui.js`：介面、音效、計時。`src/template.html`：樣式與結構。`build/build.js`：內嵌素材與模組。

`src/equipment.js`：裝備生成、品質、數值與存檔正規化。`src/gear-ui.js`：背包與地圖寶物觸控按鈕。`npm test` 含 395 項原流程檢查／120 次種子關卡模擬，另有 25 項裝備與撿寶檢查。`node tests/equipment_browser.cjs` 測實際點拾、開箱、換裝、替換、重新載入與 375×667／320×568／1280×720 畫面。

100 關是後續目標，此版只提供 10 關。未含 100 張獨立地圖、雲端存檔、商店或原生 App。
